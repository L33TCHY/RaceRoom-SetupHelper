## Deutsch

Kostenloses Setup-Tool für **RaceRoom Racing Experience**. Es liest die Live-Daten des Spiels und sagt dir, was du am Setup ändern solltest – Reifen, Fahrverhalten, Force Feedback, Pedale und Sprit, dazu Overlays im Spiel.

### Download & Installation

**[➜ Neueste Version herunterladen](../../releases/latest)** und `SetupHelper2026_Setup_<Version>.exe` starten.

- Keine Administratorrechte, kein Python nötig
- Updates kommen danach automatisch über das Tool (Menü „Updates“) – installiert wird nur auf deinen Klick
- Windows SmartScreen kann beim ersten Start warnen („Unbekannter Herausgeber“): *Weitere Informationen → Trotzdem ausführen*
- Deinstallieren: Windows-Einstellungen → Apps

### Was das Tool kann

| Bereich | Was du bekommst |
|---|---|
| Reifen | Sturz und Reifendruck aus den Temperaturen (ab 15 km Messdistanz, am genauesten ab 25 km) |
| Fahrverhalten | Unter-/Übersteuern je Kurvenphase mit passenden Setup-Hebeln |
| FFB | Clipping und Empfehlung für den FFB MULTIPLIER |
| Eingabegeräte | Bremse, Gas und Lenkrad aus den Rohwerten |
| Tank | Verbrauch pro Runde, Rennrechner, Rundenzahl über den Führenden |
| Overlays | Setup, Strecke, Reifen, Schaden – einzeln verschieb-, skalier- und transparent einstellbar |

RaceRoom im **randlosen Fenster- oder Fenstermodus** spielen, sonst sind die Overlays nicht sichtbar.

## English

Free setup tool for **RaceRoom Racing Experience**. It reads the game's live data and tells you what to change in your setup – tyres, handling, force feedback, pedals and fuel, plus in-game overlays.

### Download & installation

**[➜ Download the latest version](../../releases/latest)** and run `SetupHelper2026_Setup_<version>.exe`.

- No admin rights and no Python needed
- Updates then arrive through the tool (menu "Updates") – installed only when you click
- Windows SmartScreen may warn on first start ("unknown publisher"): *More info → Run anyway*
- Uninstall: Windows Settings → Apps

### Features

| Area | What you get |
|---|---|
| Tyres | Camber and tyre pressure from temperatures (from 15 km measured distance, most accurate from 25 km) |
| Handling | Understeer/oversteer per corner phase with matching setup levers |
| FFB | Clipping and a recommendation for the FFB MULTIPLIER |
| Input devices | Brake, throttle and wheel from the raw inputs |
| Fuel | Consumption per lap, race calculator, lap count based on the leader |
| Overlays | Setup, track, tyres, damage – each movable, scalable and with its own opacity |

Play RaceRoom in **borderless windowed or windowed mode**, otherwise the overlays are not visible.

### My guides on Steam

For a deeper dive – the background behind the tool's recommendations:

- **[Setup Hilfe / Setup Help](https://steamcommunity.com/sharedfiles/filedetails/?id=2576408471)** – which setup change fixes oversteer or understeer, by corner phase and corner speed, with the physics behind it and two cheat sheets (German and English)
- **[FFB update 2026: realistic settings for Simagic Alpha EVO Pro + GT Neo & VRS DirectForce Pro](https://steamcommunity.com/sharedfiles/filedetails/?id=3823420681)** – retuning force feedback after the Historic Update 2026, tested with Simagic and VRS hardware (German only)

### Privacy

The helper only reads data from RaceRoom, changes nothing in the game and presses no keys. It only goes online to check here for updates (can be switched off). No data about you or your driving is sent.

Please report via **[Issues](../../issues/new/choose)**. For bugs, attach the log file: in the tool *Info → Open log folder → setuphelper.log*. Issues in English are welcome.
